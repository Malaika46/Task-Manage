# 📋 Task Manage – Task Management System

Task Manage is a simple and efficient web-based Task Management System that helps users organize and manage their daily tasks easily. The application allows users to create, update, and delete tasks in a structured way, making task management simple and effective. This project demonstrates CRUD operations with a clean and user-friendly interface using modern web technologies.

## ✨ Features

* Add new tasks
* View all tasks
* Edit or update existing tasks
* Delete tasks
* Simple and clean user interface
* Organized task management
* Responsive design
